# Code of Conduct

## Our commitment

This repository welcomes respectful, constructive collaboration around SQL Full Mastery companion code, documentation, tests, and public learning resources.

## Expected behavior

- Be respectful and specific when reviewing code or reporting errors.
- Focus criticism on technical claims, reproducibility, safety, and evidence.
- Protect private information, credentials, and unpublished commercial material.
- Credit contributors appropriately.
- Avoid harassment, discriminatory conduct, threats, spam, or deliberate disruption.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, reviews, and other project-controlled collaboration spaces.
