# Contributing to SQL Full Mastery Companion Code

Thank you for improving the public companion resources for **SQL Full Mastery**.

> **Official book store:** **https://ramsandesh.gumroad.com**

## Repository boundary

Contributions may improve companion source code, tests, documentation, examples, setup instructions, CI, and public sample assets. Do not submit the paid Master PDF, DOCX, EPUB, private publishing files, secrets, or copyrighted third-party material without permission.

## Part independence

Each part under `code/part-001/` through `code/part-120/` is independent. Do not introduce cross-part runtime dependencies merely to deduplicate a small amount of code.

## Before opening a pull request

1. Keep the change scoped to one clear purpose.
2. Preserve the part's declared database/language versions.
3. Add or update tests when behavior changes.
4. Never add real credentials or personal production data.
5. Document dialect-specific SQL and operational assumptions.
6. Run the relevant package tests locally.
7. Explain any migration, compatibility, or security impact.

## Commit style

Use concise conventional-style messages such as:

- `fix(part-112): correct booking boundary check`
- `test(part-118): add peer-frame regression case`
- `docs(part-120): clarify portfolio evidence rubric`

## Reporting errors in the book

Use an issue with the affected Part number, edition, page/section if known, expected behavior, and evidence. Do not paste large portions of the paid manuscript into public issues.
