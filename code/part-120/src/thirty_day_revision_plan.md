# 30-Day Revision Plan

- Days 1-3: baseline mock, error log, target role, portfolio inventory.
- Days 4-7: joins, grouping, subqueries, windows, NULLs, deterministic ordering.
- Days 8-10: schema, keys, constraints, normalization, history, tenant scope.
- Days 11-13: transactions, isolation, locks, deadlocks, idempotency, outbox.
- Days 14-16: indexes, plans, statistics, skew, pagination, partitioning.
- Days 17-19: analytics cases, sessions, funnels, cohorts, temporal joins.
- Days 20-21: migrations, security, privacy, backup, restore, reconciliation.
- Days 22-24: three role-specific mock loops and answer rewrites.
- Days 25-26: portfolio README, demo script, evidence matrix, resume bullets.
- Days 27-28: behavioral stories, stakeholder explanation, incident story.
- Day 29: full 120-minute mock with independent scoring.
- Day 30: final checklist, application plan, and next 30-day maintenance cadence.

Daily minimum: one closed-book answer, one adversarial test, one rewritten explanation, and one recorded score.
