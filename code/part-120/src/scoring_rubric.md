# 100-Point Final Scoring Rubric

| Dimension | Points | Full-credit evidence |
|---|---:|---|
| Clarification and contract | 10 | Grain, identity, time, NULL, scale, consistency, and failure assumptions |
| Query correctness | 15 | Correct rows, deterministic order, ties, boundaries, adversarial proof |
| Data model and integrity | 15 | Keys, constraints, cardinality, history, tenant scope, invariant owner |
| Transactions and concurrency | 15 | Boundary, anomaly, lock/isolation/version, idempotency, retry class |
| Performance reasoning | 10 | Representative plan, estimates, loops, I/O/memory, measured trade-off |
| Evolution and operations | 10 | Expand-contract, observability, reconciliation, backup/restore, runbook |
| Security and privacy | 10 | Least privilege, injection safety, tenant/PII controls, negative tests |
| Communication | 10 | Structured, concise, assumptions stated, alternatives and risks explained |
| Portfolio evidence | 5 | Reproducible project artifacts supporting claims |

**Readiness bands:** 90-100 ready for strong loops; 80-89 ready with targeted repair; 70-79 schedule more mocks; below 70 rebuild foundations before high-stakes interviews.
