# Six Final Mock Interview Loops

## Mock 1 - SQL Analyst / Product Analytics (60 minutes)

1. Clarify a weekly active-user metric and its time zone, identity, and duplicate-event rules.
2. Write a deterministic top-three products per category query with ties explained.
3. Build a strict view -> cart -> purchase funnel within seven days.
4. Calculate cohort retention with a fixed denominator and zero-activity periods.
5. Diagnose an apparent revenue increase caused by a mixed-grain join.
6. Explain NULL-safe anti-joins and test data.
7. Review one execution plan and propose measured changes.
8. Present results to a non-technical stakeholder with limitations.

## Mock 2 - Analytics Engineer (75 minutes)

Design a governed revenue mart. Define source contracts, staging, dimensions, fact grain, late-arriving data, Type 2 history, tests, incremental replay, freshness, reconciliation, lineage, access control, deployment, rollback, and dashboard certification.

## Mock 3 - Backend / Product Engineer (75 minutes)

Design checkout with catalog snapshots, inventory reservation, idempotent order creation, payment uncertainty, outbox events, cancellation/refund, row-level security, indexes, migration compatibility, monitoring, and reconciliation.

## Mock 4 - Data Engineer (75 minutes)

Design a replay-safe event pipeline from mutable operational sources into an analytical warehouse. Cover watermarks, CDC ordering, schema evolution, dedupe, late events, backfill, partitioning, quality gates, observability, cost, and recovery.

## Mock 5 - DBA / DBRE / Platform Engineer (90 minutes)

A latency incident follows a release. Analyze plans, estimates, locks, pool saturation, vacuum/statistics, replication, storage, and query changes. Then design containment, safe rollout, backup/PITR verification, and incident evidence.

## Mock 6 - Senior Cross-Functional Loop (120 minutes)

- 25 min live SQL challenge
- 30 min schema and concurrency design
- 20 min performance diagnosis
- 15 min migration and security review
- 15 min portfolio deep dive
- 15 min behavioral and communication questions

For every mock, reserve the final ten minutes for self-scoring, one rewritten answer, and one targeted revision action.
