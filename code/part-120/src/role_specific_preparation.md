# Role-Specific Preparation

## SQL / Data Analyst
Prioritize metric contracts, joins, aggregation, windows, cohorts, experiments, data quality, communication, and one dashboard case.

## Analytics Engineer
Prioritize dimensional modeling, source contracts, dbt-style testing, incremental state, Type 2 history, lineage, freshness, deployment, and governance.

## Data Engineer
Prioritize ingestion, CDC, ordering, idempotency, late data, partitions, backfills, distributed failure, observability, cost, and recovery.

## Backend Engineer
Prioritize OLTP schema design, transactions, locks, idempotency, outbox/inbox, migrations, indexes, security, and API failure semantics.

## DBA / DBRE
Prioritize plans, statistics, maintenance, locks, replication, capacity, backup/PITR, upgrade, incident response, and operational automation.

## Data Platform / Database Engineer
Prioritize multi-tenancy, workload isolation, connection management, schema governance, migration orchestration, reliability, security, and developer experience.

For each target role, choose two primary projects and one backup project. Prepare a 30-second summary, a three-minute story, a ten-minute deep dive, and a failure/recovery story for each.
