# Five-Step SQL Interview Answer Framework

1. **Define** - one precise sentence.
2. **Distinguish** - contrast the nearest confusing concept.
3. **Demonstrate** - use a tiny schema, query, or data example.
4. **Warn** - identify a common pitfall, edge case, or dialect difference.
5. **Verify** - explain how the answer or query would be tested.

## Four-point rubric

- 0: incorrect or unsafe
- 1: partially correct
- 2: correct definition plus example
- 3: definition, contrast, example, and pitfall
- 4: adds assumptions, edge cases, verification, and concise communication
